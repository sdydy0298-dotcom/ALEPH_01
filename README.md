# SKT ALEPH Assignment 01

SKT ALEPH 과정의 첫 번째 과제인 **'나를 소개하는 한 페이지'** 프로젝트입니다.

링크 하나로 제가 어떤 사람인지, 무엇을 좋아하는지, 어떤 경험을 해왔는지 보여주는 개인 자기소개 페이지입니다.  
공개 범위를 직접 정하고, 경험과 강점을 상황·행동·결과와 함께 확인할 수 있도록 구성했습니다.

## Features

- 자기소개 및 프로필 정보
- 좋아하는 것 표시
- MY JOURNEY를 통한 경험 흐름 정리
- 3가지 강점과 Situation / Action / Result 상세 콘텐츠
- 1번 강점에 공개 가능한 Evidence 링크 제공
- 강점 카드 마우스 및 키보드 상호작용
- 공개 / 비공개 정보 범위 표시
- 반응형 레이아웃
